# Audit Remediation Assumptions & Conservative Decisions

This document records all autonomous engineering decisions made under the conservative default rule.

| Decision ID  |     Ticket / Scope      | Context & Options                                                       | Chosen Decision (Most Conservative)                                                                                                                                                                                                                                               | Rationale / ADR Reference                                                                |
| :----------- | :---------------------: | :---------------------------------------------------------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :--------------------------------------------------------------------------------------- |
| **A-S1**     |      T1 (Security)      | Master key validation: What if `KEEL_MASTER_KEY` is invalid at startup? | Throw error and halt server startup if `KEEL_MASTER_KEY` is missing, < 32 chars, or equals default string. SecretVault constructor throws immediately.                                                                                                                            | S1 pre-made decision; prevents unencrypted/insecure vault state.                         |
| **A-S2**     |      T1 (Security)      | Throttling storage & scope: Persist failed login attempts in SQLite.    | Table `auth_rate_limits (key TEXT PRIMARY KEY, attempts INTEGER, first_attempt_ms INTEGER, locked_until_ms INTEGER)`. Exponential backoff starts after 5 failed attempts within 15m. Applied to `/login`, `/step-up`, `/bootstrap`.                                               | S2 pre-made decision; survives server restarts and node cluster reboots.                 |
| **A-FMT**    |      T1 (Security)      | Versioned format migration: Support legacy hashes and ciphertexts.      | Hashes prefixed with version string `argon2id$v=1$...`. Legacy unversioned hashes re-hashed on valid login. Vault ciphertexts versioned `v1:...`. Legacy ciphertexts decrypted and re-encrypted on write.                                                                         | Eliminates silent breaking changes while transparently migrating storage.                |
| **A-R1**     |   T2 (Replay Realism)   | Exit adverse slippage & stress multiplier.                              | Slippage penalty applied to stop market exits and liquidation market exits, but NOT to limit take-profit fills. Cost stress multiplier scales both fees AND slippage. Shared in `@keel/core/execution.ts`.                                                                        | R1 pre-made decision; prevents optimistic fill assumptions.                              |
| **A-R2**     |  T3 (Trial Accounting)  | Trial counter definition & sequence.                                    | New table `research_trial_sequence (id INTEGER PRIMARY KEY AUTOINCREMENT, program_id TEXT, parameter_hash TEXT, instrument_id TEXT, timeframe TEXT, recorded_at_ms INTEGER)`. Counter strictly non-decreasing. Replaces `INSERT OR REPLACE` with plain `INSERT` in `experiments`. | R2 pre-made decision; immutable audit trail of all research trials.                      |
| **A-R4**     | T3 (Holdout Quarantine) | 2026 Holdout quarantine enforcement.                                    | Reject any request accessing data >= `SEALED_2026_HOLDOUT_START_TS` unless `allowHoldoutAccess === true` AND a single-use token row exists in `holdout_access_tokens` table.                                                                                                      | R4 pre-made decision / ADR-0011.                                                         |
| **A-R6**     | T5 (Scheduler Catch-up) | Confirmed bar processing backlog.                                       | Process all unconfirmed bars in chronological order, capped at 500 bars per step. Default `schedulerStrategies` configuration is empty (`[]`).                                                                                                                                    | R6 pre-made decision; prevents missed fills/funding while bounding memory/runtime.       |
| **A-SHADOW** |    T7 (Shadow Gate)     | Shadow pick lifecycle & resolution.                                     | Record shadow pick with signal bar timestamp; resolve later against subsequent bars to calculate actual $R$. Require non-negative resolved expectancy and at least `shadowMinTrades`.                                                                                             | Shadow gate decision; prevents unconfirmed shadow trades from counting toward promotion. |
